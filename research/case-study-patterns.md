## Sanvithi Deep Dive: Interaction Mechanics

### The Pinned Scrollytelling Pattern

**What it does**:
When user scrolls through Design sections (1/3, 2/3, 3/3), the left column containing the section title and description stays pinned (fixed) while the right column containing feature images and annotations scrolls vertically through multiple states.

**Scroll positions and triggers**:
1. **Enter trigger**: When section enters viewport top
2. **Pin start**: Section header pins to left ~40% of screen
3. **Content scroll**: Right side scrolls through 2-3 image states per section
4. **Pin end**: When all images have scrolled, section unpins and scrolls away
5. **Duration**: Approximately 150-200vh of scroll distance per pinned section

**Animation timing/easing**:
- Pin: Instant snap to fixed position
- Image transitions: Smooth opacity/transform (likely ~0.3s ease-out)
- Content reveals: Staggered fade-in on scroll

**State changes**:
```
State 1: Section title + description pinned left | First image visible right
State 2: Same text pinned | Second image scrolls in, first fades
State 3: Same text pinned | Third image scrolls in, second fades
State 4: Section unpins | Next section begins
```

**Technical implementation approach**:
```tsx
// Using GSAP ScrollTrigger
ScrollTrigger.create({
  trigger: ".design-section",
  start: "top top",
  end: "+=200%",  // 2x viewport height of scroll
  pin: ".section-text",  // Pin only the text column
  scrub: 1,
  onUpdate: (self) => {
    // Update which image is visible based on scroll progress
    const progress = self.progress;
    // 0-0.33: image 1, 0.33-0.66: image 2, 0.66-1: image 3
  }
});
```

## Cross-Site Synthesis

### Common Section Structures

| Position | Most Common Sections |
|----------|---------------------|
| 1 | Hero (title, role, outcome, metadata) |
| 2 | Context / Background / Problem |
| 3 | Goals / Challenge statement |
| 4 | Research / User understanding |
| 5 | Process / Key decisions |
| 6 | Solution / Features walkthrough |
| 7 | Impact / Metrics |
| 8 | Reflection / Learnings |
| 9 | Next steps / Future |

### Best-in-Class Patterns

**1. Outcome-First Hero (Sanvithi, Fabio)**
- Lead with the result, not the process
- Large, bold outcome statement
- Metrics visible above fold

**2. Numbered Progression (Sanvithi, Design System)**
- Sections like "Design 1/3, 2/3, 3/3"
- Creates clear narrative arc
- Reader knows where they are

**3. Pinned Scrollytelling (Sanvithi)**
- Context stays fixed while evidence scrolls
- Perfect for feature explanations
- Reduces cognitive load

**4. Interactive Question Prompts (Caleb)**
- "What problem was this solving?"
- Engages reader, answers obvious questions
- Shows self-awareness

**5. Before/After with Labels (Himesh, Jon)**
- Clear visual distinction
- Context for the change
- Side-by-side comparison

**6. Metric Callouts (Sanvithi, Fabio)**
- Large, prominent numbers
- Simple labels
- Visual emphasis on impact

**7. Process Reframing (Design System)**
- "Instead of asking X, we asked Y"
- Shows strategic thinking
- Demonstrates senior judgment

**8. Honest Constraints (Siyona, Sanvithi)**
- What couldn't be done
- Time/resource limitations
- Builds credibility

### Navigation Patterns

| Pattern | Examples | Best For |
|---------|----------|----------|
| Sticky progress bar | Himesh | Long-form |
| Section-based sticky nav | Design System | Dense content |
| Minimal fixed header | Sanvithi, Fabio | Clean narrative |
| None (pure scroll) | Swiggy article | Editorial |

### Mobile Considerations

- All studied sites are responsive
- Pinned sections collapse to stacked on mobile
- Galleries become vertical scrolls
- Metrics stack vertically
- Navigation simplifies to hamburger

## Concrete Improvements to Casestack Architecture

Based on this research, update the 13-section structure:

### Section Order Refinements

1. **Hero** - Keep, add outcome-first emphasis
2. **TL;DR** - Keep, ensure it's truly scannable
3. **Context** - Keep, combine with problem
4. **My Role** - Move earlier (after context), add team composition
5. **Constraints** - Add explicit section, document limitations
6. **Research** - Keep, emphasize key insights with numbers
7. **Problem Framing** - Keep HMW format
8. **Process** - Add numbered progression (Phase 1/3, 2/3, 3/3)
9. **Solution** - Split into numbered features with pinned scroll option
10. **Validation** - Keep, add iteration stories
11. **Impact** - Elevate importance, large metric callouts
12. **Reflection** - Keep, add "what I'd change"
13. **Next Steps** - Keep, show forward thinking

### New Components to Add

1. **ScrollytellingSections** - Sanvithi-style pinned scroll
2. **NumberedPhase** - "1/3, 2/3, 3/3" progression indicator
3. **MetricHero** - Large outcome metrics above fold
4. **InteractivePrompts** - "Ask me about..." expandable
5. **ScrollProgress** - Chapter-based progress indicator
6. **HorizontalGallery** - Drag/scroll image gallery
7. **ImageComparisonSlider** - Before/after with draggable divider
8. **CountUpMetric** - Animated number on scroll

### Rubric Additions

Add to senior rubric scoring:

| Signal | What to look for |
|--------|-----------------|
| Outcome-first framing | Is impact visible in first viewport? |
| Clear progression | Are phases/steps numbered? |
| Visual evidence | Does solution show, not just tell? |
| Constraints honesty | Are limitations acknowledged? |
| Forward thinking | Is "what's next" documented? |
