# Fictional Case Study Example

This directory contains a complete example case study using fictional data. Use it as a reference for structure, content depth, and formatting.

## Files

- `content.json` - Structured content model following the CaseStudy schema
- `page.mdx` - Written case study in MDX format

## About This Example

**Project:** Acme Commerce Checkout Redesign  
**Role:** Lead Product Designer  
**Company:** Acme Commerce (fictional)

This example demonstrates:

1. **Complete content model** - All fields populated with realistic (but fictional) data
2. **Senior-level signals** - Ownership, strategy, impact, collaboration, reflection
3. **Writing quality** - Outcome-first, concise, specific, no AI slop
4. **Visual structure** - Clear sections, tables, quotes, metrics

## Using This Example

### As a Template

Copy `content.json` and replace values with your real project data.

### As a Reference

Compare your case study against this example to check:
- Are all sections present?
- Is the depth of detail similar?
- Are metrics as specific?
- Is the tone outcome-first?

### For Validation

Run the validation script to see a passing example:

```bash
npm run validate
```

## Disclaimer

All data in this example is fictional:
- "Acme Commerce" is not a real company
- All metrics are fabricated for demonstration
- Team members and quotes are invented
- No real proprietary information is included

This example exists solely to demonstrate the expected structure and quality of a senior-level portfolio case study.
